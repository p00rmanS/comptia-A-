# Core 2 first milestone

Four introductory workshops, 12 original checks, and a course selector. Core 1 remains the default and retains its 65 lesson identities and original storage key. Core 2 uses `core-two-mentor-v1`. Notes, completion, practice, and ratings are independent. Ports remain a Core 1 exercise.

The shared renderer provides English/Taglish explanations, concept flows, vocabulary, worked paper labs, checks, flashcards, practice, search, and export. No full coverage or exam readiness claim is made.

Scope reference: [CompTIA-authored 220-1202 objectives, version 2.0, hosted by ONLC](https://www.onlc.com/comptia/comptia-a-220-1202-exam-objectives.pdf). Verified domain weights and selected mappings 1.1, 2.1/2.2, 3.1, and 4.1. The app links to CompTIA’s A+ page for current objectives; the hosted version is not claimed to be the latest revision.

Browser verification passed against the production preview: all Core 2 routes, 20 lesson sections, 12 answers, completion after reload, notes, practice bank limits, desktop/mobile course switching, independent Core 1 storage, and mobile overflow checks. Zero captured browser errors. Desktop and mobile screenshots were reviewed. Syntax and whitespace checks pass.
