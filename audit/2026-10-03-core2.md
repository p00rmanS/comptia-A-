# Core 2 teaching expansion — October 3, 2026

Added 12 original guided workshops and 36 checks, bringing Core 2 to 16 lessons and 48 checks. Each workshop includes three learning goals, English/Taglish teaching, an analogy, vocabulary, four or more guided steps, a concept flow, a worked paper lab, a common confusion, a recap, related lessons, and three questions explaining the choices.

## Learning sequences

- OS: foundations → installation → filesystems → Windows tools → Windows commands → Linux basics.
- Security: accounts → share/NTFS permissions → phishing → malware response.
- Troubleshooting: app scope → Windows recovery → mobile apps.
- Operations: support tickets → backups → change management.

The original four IDs, numbers, question text, and rotated answer choices are protected by a compatibility digest. Existing Core 1 and Core 2 browser storage keys are retained. New lessons participate in search, flashcards, domain and mixed practice, missed-question review, notes, bookmarks, and completion totals.

Scope remains selected concepts rather than full objective coverage. All labs are paper exercises with worked solutions; no commands are executed by the learning app. Full mock exams and interactive PBQ simulations are not included. The Resources page provides suggested sequences and reference links with dynamic lesson/question totals.

Teaching stresses limits of evidence: successful ping is not application health, Safe Mode success is not proof of a single cause, cache and app-data deletion differ, and a backup success log does not establish a working restore. Permission examples are explicitly simplified allow-only cases. Exam SOHO malware procedures are distinguished from managed incident response.
