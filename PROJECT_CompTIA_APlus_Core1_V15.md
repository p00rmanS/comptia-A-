# CompTIA A+ Core 1 Learning Platform — PROJECT.md

## 1. Project Overview

Build a polished, interactive, Coursera/Udemy-style web learning platform for:

# CompTIA A+ Core 1 V15
**Exam Code:** 220-1201  
**Certification:** CompTIA A+  
**Primary Goal:** Teach a complete beginner enough practical knowledge and exam strategy to confidently prepare for and pass CompTIA A+ Core 1.

The platform should feel like a real online course, not a static notes website.

It must teach concepts using:

- Simple English
- Taglish explanations
- Everyday analogies
- Visual examples
- Step-by-step lessons
- Key terms
- “Why this matters” explanations
- Real IT support examples
- Troubleshooting scenarios
- Practice questions
- Performance-based question simulations
- Mini labs
- Knowledge checks
- Module quizzes
- Full mock exams
- Progress tracking
- Review mode
- Weak-area tracking

The learner may have little or no prior IT knowledge.

The platform must therefore explain concepts from the ground up without assuming the learner already understands technical terminology.

# 4. Primary Learning Philosophy

The platform should teach using this sequence:

> Understand → Visualize → Apply → Troubleshoot → Test → Review

Every important topic should answer:

1. What is it?
2. Why does it exist?
3. Where would I see it?
4. How does it work?
5. What does it connect to?
6. What does CompTIA expect me to know?
7. What could go wrong?
8. How would a technician fix it?
9. What words in an exam question should trigger this concept?
10. How might this appear in a PBQ?

Do not teach through definition dumping.

Teach through understanding.

---

# 5. Teaching Style

## Required Language Style

Default explanation style:

**Simple English + Taglish**

Example:

> RAM is the computer's short-term working memory.  
>
> Parang work table mo siya. Kapag maraming space ang table, mas maraming bagay ang pwede mong gawin sabay-sabay. Pero kapag pinatay mo ang computer, mawawala ang laman ng RAM.

The learner should feel like a knowledgeable Filipino IT mentor is explaining the concept casually but accurately.

---

# 6. Explanation Levels

Every lesson should support three explanation modes.

## Level 1 — Super Simple

For complete beginners.

Example:

> DNS converts website names into IP addresses.

Taglish:

> Parang contacts app ng internet. Hindi mo kailangang tandaan ang number ng server; DNS ang naghahanap ng IP address para sa iyo.

---

## Level 2 — Exam Ready

Explain the actual terminology CompTIA may test.

Example:

> DNS typically uses UDP port 53 for standard queries and TCP port 53 for larger responses and zone transfers.

---

## Level 3 — Technician View

Explain what happens in real IT work.

Example:

> If a user can ping `8.8.8.8` but cannot open `google.com`, investigate DNS before assuming the internet connection is down.

# 11. CompTIA Troubleshooting Methodology

Teach and repeatedly reinforce the standard troubleshooting mindset.

Use a visually memorable workflow.

Example conceptual workflow:

1. Identify the problem
2. Establish a theory of probable cause
3. Test the theory
4. Establish a plan of action
5. Implement the solution
6. Verify full functionality
7. Document findings

Create scenario exercises where the learner must choose the correct next step.

Important:

The learner should not only know **the solution**.

They must understand **the correct troubleshooting order**.

# 41. Question Quality Requirements

Questions should resemble the reasoning style of certification questions.

Bad:

> What is DNS?

Better:

> A technician confirms that a workstation can successfully ping `8.8.8.8`, but the user cannot browse to `example.com`. Which service should the technician investigate FIRST?

Questions should test:

- Recognition
- Application
- Troubleshooting
- Best answer
- First step
- Most likely cause
- Best tool
- Best connector
- Correct protocol

---

# 42. Question Difficulty

## Easy

Direct recognition.

## Medium

Concept applied to a scenario.

## Hard

Requires eliminating several plausible answers.

Example:

> A laptop connects to Wi-Fi but cannot access websites by hostname. Other devices are working normally. The technician successfully pings a public IP address. Which configuration should be checked NEXT?

---

# 43. Explanation Style for Questions

Every answer should show:

```text
Correct: B — DNS configuration

Why:
The computer can reach an external IP address, so basic network connectivity is working.

The failure happens only when resolving names.

Exam clue:
"Can ping IP but cannot access hostname."

Why not A:
DHCP already gave the computer working network settings.

Why not C:
The wireless connection is already established.

Remember:
IP works + hostname fails = think DNS.
```

Also include a Taglish explanation.
